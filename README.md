# سیمرغ‌دستگاه (simorgh-device)

اپلیکیشن **اندروید (Flutter)** برای تبدیل یک تبلت/گوشی به **دستگاه حضور و غیاب**
سامانهٔ [سیمرغ‌کارا](https://github.com/shahram-tabasi/simorgh-kara) — با **تشخیص چهرهٔ روی‌دستگاه**
و گزینهٔ تردد دستی.

این کد **جدا از مخزن سیمرغ‌کارا** نگه‌داری می‌شود و فقط از طریق APIهای دستگاهِ سیمرغ‌کارا به آن وصل می‌شود.

---

## این اپ چه می‌کند؟
- پیش‌نمایش زندهٔ دوربین جلو روی یک تبلت دمِ درب.
- تشخیص چهره روی خود دستگاه (Google ML Kit) و ساخت **امبدینگ** با مدل TFLite (MobileFaceNet).
- ارسال امبدینگ به سرور برای **شناسایی و ثبت خودکار ورود/خروج**.
- **ثبت چهرهٔ کارمندان** (enrollment) از همین دستگاه.
- **تردد دستی** با ایمیل کارمند (در صورت نبود چهره).
- تنظیمات کامل دستگاه: آدرس سرور، شرکت، توکن، جهت تردد، عکس و GPS.

> 🔒 چهرهٔ خام هیچ‌گاه از دستگاه خارج نمی‌شود؛ فقط بردار عددی (امبدینگ) به سرور می‌رود.
> سرور آن را L2-نرمال و با شباهت کسینوسی تطبیق می‌دهد.

---

## اتصال به سیمرغ‌کارا
اپ با سه نقطهٔ پایانی موجود در سیمرغ‌کارا کار می‌کند (با هدر `Authorization: Bearer <device-token>`):

| کار | متد و مسیر |
|---|---|
| ثبت تردد دستی | `POST /api/<slug>/attendance/ingest` |
| شناسایی چهره + ثبت خودکار | `POST /api/<slug>/attendance/face/identify` |
| ثبت چهرهٔ کارمند | `POST /api/<slug>/attendance/face/enroll` |

### گرفتن توکن دستگاه
۱. در سیمرغ‌کارا با حساب مدیر/کارگزینی وارد شوید.
۲. به **حضور و غیاب ← دستگاه‌های تردد** بروید و یک دستگاه جدید بسازید.
۳. مقدار **token** و **اسلاگ شرکت** را بردارید و در صفحهٔ تنظیمات این اپ وارد کنید.

---

## راه‌اندازی
نیازمندی‌ها: Flutter (نسخهٔ 3.24 یا جدیدتر) و Android SDK.

</div>

```bash
# ۱) پلتفرم اندروید را تولید کنید (فایل‌های gradle و ... را می‌سازد و فایل‌های موجود را دست نمی‌زند)
flutter create --org ir.simorghkara --platforms=android .

# ۲) مدل تشخیص چهره را اضافه کنید  (راهنما: assets/models/README.md)
#    assets/models/mobilefacenet.tflite

# ۳) وابستگی‌ها و اجرا
flutter pub get
flutter run            # یا: flutter build apk --release
```

## ورود اپراتور (لاگین)
هنگام اجرا، اگر برای دستگاه گذرواژه تعریف شده باشد، ابتدا صفحهٔ **ورود** نمایش
داده می‌شود و ترمینال تا ورود موفق قفل است. مقادیر پیش‌فرض برای تست:

- **نام کاربری:** `admin`
- **گذرواژه:** `1234`

این مقادیر را می‌توانید در **تنظیمات دستگاه** تغییر دهید. اگر گذرواژه را خالی
بگذارید، صفحهٔ ورود نمایش داده نمی‌شود.

> ثبت چهره و تردد دستی با **کد پرسنلی** انجام می‌شود (ایمیل اختیاری است).

## تنظیمات اولیه روی دستگاه
بعد از نصب، در اولین اجرا صفحهٔ تنظیمات باز می‌شود:
- **آدرس سرور**: مثلاً `https://app.simorghkara.ir`
- **اسلاگ شرکت**: مثلاً `aahangari-demo`
- **توکن دستگاه**: از سیمرغ‌کارا
- **جهت ثبت تردد**: فقط ورود / فقط خروج / پرسش از کاربر
- ثبت خودکار، ضمیمهٔ عکس، GPS و آستانهٔ تطبیق چهره (اختیاری)

سپس از نوار بالای صفحهٔ اصلی: 👤 ثبت چهرهٔ کارمندان، ⌨ تردد دستی، ⚙ تنظیمات.

## ساختار کد

</div>

```
lib/
  main.dart                      نقطهٔ ورود + مسیر اولیه (ترمینال یا تنظیمات)
  src/
    config/app_config.dart       مدل تنظیمات
    config/config_store.dart     ذخیره در SharedPreferences
    api/api_client.dart          اتصال به APIهای سیمرغ‌کارا
    face/face_embedder.dart      اجرای مدل TFLite (امبدینگ چهره)
    face/face_service.dart       تشخیص + برش چهره + امبدینگ
    ui/terminal_screen.dart      صفحهٔ اصلی (کیوسک تردد)
    ui/settings_screen.dart      تنظیمات دستگاه
    ui/enroll_screen.dart        ثبت چهرهٔ کارمند
    ui/manual_punch_screen.dart  تردد دستی
    ui/theme.dart                تم تیره/طلایی هماهنگ با سیمرغ‌کارا
```
