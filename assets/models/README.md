# مدل تشخیص چهره (TFLite)

این پوشه باید شامل یک فایل مدل MobileFaceNet/FaceNet با نام زیر باشد:

```
assets/models/mobilefacenet.tflite
```

این فایل **به‌صورت عمدی در گیت ذخیره نمی‌شود** (در `.gitignore` است) چون یک باینری بزرگ است.

## مشخصات مدل سازگار
- ورودی: تصویر چهرهٔ `112×112×3` (float، نرمال‌شده به بازهٔ `[-1, 1]`).
- خروجی: بردار امبدینگ (معمولاً ۱۲۸ یا ۱۹۲ بعدی).
- اپ به‌صورت خودکار اندازهٔ ورودی و طول خروجی را از خود مدل می‌خواند.

## از کجا تهیه کنیم
هر مدل MobileFaceNet آموزش‌دیده با همین قرارداد ورودی/خروجی کار می‌کند. نمونه‌های رایج
(MobileFaceNet) به‌صورت `mobilefacenet.tflite` در مخازن متن‌باز در دسترس‌اند.
فایل را اینجا قرار دهید و سپس:

```bash
flutter pub get
flutter run
```

> سمت سرور سیمرغ‌کارا فقط بردار L2-نرمال‌شده را ذخیره و با شباهت کسینوسی تطبیق می‌دهد؛
> هیچ پردازش تصویری روی سرور انجام نمی‌شود و چهرهٔ خام از دستگاه خارج نمی‌شود.
